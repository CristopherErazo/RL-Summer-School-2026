## Summary
Monte Carlo Tree Search deals with the problem of planning. Which action should the agent take now to maximise future rewards.

We dont want to run an exhaustive search. 

MCTS tries trajectories selectively if they are promising. 

**Game Trees for Planning**

We view the MDP as a two player game:
- agent that chooses actions
- enviromnent that samples the next state

Current state is the root node. Each child node keeps track of its parent, the cumulative reward obtained in that state and number of times visited?
